# 지온의 하루

지온이와 엄마·아빠가 함께 쓰는 가족 앱입니다.
안드로이드 앱(홈 화면 위젯 포함)과 웹 화면이 같은 기록을 봅니다.

## 들어 있는 것

| 폴더 | 내용 |
| --- | --- |
| `web/` | 앱 화면 전체 (GitHub Pages로 자동 배포) |
| `android/` | 안드로이드 앱과 홈 화면 위젯 |
| `firestore.rules` | 저장소 보안 규칙 |

## 아빠가 한 번만 해주실 것

### 1. 파이어베이스(무료 저장소) 만들기

1. <https://console.firebase.google.com> 에 들어가 구글 계정으로 로그인합니다.
2. **프로젝트 만들기** → 이름은 `jion-day` 로 하고 다음을 누릅니다.
3. 애널리틱스(분석)는 **사용 안 함**으로 두고 만듭니다.
4. 왼쪽 메뉴 **빌드 → Firestore Database** → **데이터베이스 만들기**
   - 위치는 `asia-northeast3 (서울)`
   - **프로덕션 모드**로 시작합니다.
5. 왼쪽 메뉴 **빌드 → Authentication** → **시작하기** → **익명(Anonymous)** 을 켭니다.
6. **규칙(Rules)** 탭에 이 저장소의 `firestore.rules` 내용을 붙여 넣고 **게시**합니다.
7. 왼쪽 위 **⚙ 프로젝트 설정** → 아래로 내려 **내 앱** → **웹(`</>`)** 아이콘을 누릅니다.
   - 앱 이름은 아무거나, 호스팅은 체크하지 않습니다.
   - 나오는 `firebaseConfig = { ... }` 를 **통째로 복사**합니다.

### 2. 앱에 붙여 넣기

1. 앱을 처음 열면 "저장소 연결하기" 화면이 나옵니다.
2. 복사한 설정을 붙여 넣고 **연결하기**를 누릅니다.
3. **새로 시작하기**를 누르면 가족 코드가 만들어집니다.
4. 다른 기기(엄마 폰 등)에서는 같은 설정을 붙여 넣은 뒤,
   **설정 → 가족 코드 보기**에 나온 코드를 입력해 **이 코드로 들어가기**를 누릅니다.

### 3. 앱 설치하기

1. 이 저장소의 **Releases** 에서 `app-debug.apk` 를 태블릿으로 내려받습니다.
2. 태블릿 설정에서 **알 수 없는 앱 설치**를 허용한 뒤 파일을 눌러 설치합니다.
3. 홈 화면을 길게 눌러 **위젯 → 지온의 하루**를 홈 화면에 올립니다.

## 위젯에 나오는 것

- 엄마·아빠가 보낸 메시지
- 오늘 할 일 (체크된 것은 ☑)
- 오늘 요일의 스케줄
- 오늘 준비물

15분마다, 그리고 앱을 닫을 때마다 새로 받아 옵니다.
위젯 오른쪽 위 **새로고침**을 누르면 바로 받아 옵니다.

## 고칠 때

`web/` 안의 내용을 고쳐 `main` 에 올리면 GitHub Pages가 자동으로 새로 배포합니다.
앱은 그 주소를 열기 때문에, **앱을 다시 설치하지 않아도 최신 화면이 됩니다.**
위젯이나 앱 껍데기 자체를 고칠 때만 새 `apk` 를 설치하면 됩니다.
